# Стратегия Океан Тех

Рабочие документы по движению к цели: оценка группы $1 млрд через 18 месяцев после получения $50 млн.

| Файл | Что это |
|---|---|
| `90-day-plan.md` | Операционный план на первые 90 дней: понедельный план по трём направлениям, ритм управления, гайд интервью, скоринг отрасли, структура пилота |
| `target-state-18m.md` | Целевое состояние на 18-й месяц и контрольные точки по кварталам |
| `roles.md` | Пять владельцев результата: миссия, результаты по срокам, профиль, где искать |
| `thesis-vs-product.md` | Что говорим и что продаём: тезис как рамка, продукт по тому, что покупают; роль метаинфлюенсеров; рабочие имена группы и направлений |
| `deck-rebuild.md` | Пересборка деки: диагноз, карта «рассказ → слайд», новая структура на 15 слайдов, факты для подтверждения, решения |
| `industry-selection.md` | Выбор первой отрасли для ИИ-сотрудников: сводный скоринг семи кандидатов и рекомендация |
| `research/` | Досье по отраслям-кандидатам и плейбук компаний категории «ИИ-сотрудник», с источниками |
