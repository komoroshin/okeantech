# Пересборка деки: от рассказа к слайдам

Версия 0.1 · 12.09.2026 · источники: транскрипт встречи 08.09.2026 (Дмитрий, Константин, Алексей), дека v5 (30 слайдов)

## Диагноз в трёх строках

Рассказ Константина это причинная цепочка с доказательствами: сдвиг в мире → новый участник → три атрибута → три бизнеса → мы уже это делаем → экономика («это ФОТ, а не софт») → сравнимые компании → план. Дека v5 это классификация: пять слайдов определений, ноль фактов «мы уже делаем», три симметричных направления без разницы в горизонте денег, нет ответа «что получает инвестор». Пересобираем деку по сценарию рассказа: один слайд на один смысловой удар, заголовок это фраза, которая была сказана вслух.

## Принципы текста

- Заголовок слайда это сказанная фраза, а не название раздела. «Это не рынок софта, это фонд оплаты труда», а не «Рынок больше бюджета на софт».
- Глаголы и бытовые слова: агент, кошелёк, сотрудник, чек, договор. Не «институты», не «инфраструктура», не «полномочия».
- На слайде одна мысль и один вывод внизу. Таблицы и сноски в приложение.
- Каждое направление получает факт о нас раньше, чем факт о рынке.
- Дека должна работать без Константина: её покажет Алексей человеку, которого мы не увидим.

## Факты для подтверждения до написания слайда 5

Из рассказа, нужны точные формулировки и разрешение называть:

| Факт | Что уточнить |
|---|---|
| DevOps-агент заменяет живого DevOps | С какого месяца, какие задачи, сколько задач в неделю |
| Помощник юриста | Сделан или «можем сделать» |
| Задачи для Atom, ProofUp, Arena | Что именно, можно ли называть клиентов |
| Персонажи для Instagram | Чьи, какие охваты, можно ли показать |
| ИИ-сериал для ретейл-бренда | Стадия переговоров, можно ли называть бренд |
| Кукла-робот для Анимаккорда | Договор подписан, можно ли называть, срок |
| Вирусные ролики с миллионными охватами | Какие, сколько просмотров, ссылки |
| Внутренний биллинг токенов | Что считает, сколько продуктов подключено |
| Arena, ProVide (ProofUp) | Что это за продукты, для кого, статус |
| Команда из шести ИИ-агентов с именами (Аня готовит) | Готово ли к дате деки, показываем или нет |

## Решения, которые нужны от Дмитрия и Константина

1. **Билет.** Дмитрий на встрече сказал, что $50 млн это гибкая цифра, возможны 5 или 10. В деке цифра жёсткая. Предлагаю не менять $50 млн как программу, а показать этапы: билет на $10 млн финансирует первые два этапа, это уже есть в бюджете. Тогда история одна, а вход разный.
2. **Структура для инвестора.** На встрече обсуждались одна компания с тремя ответвлениями, доля, дивиденды или выход. Для слайда 15 нужна одна согласованная формулировка, без деталей внутренних договорённостей.
3. **Имена.** Aikumena, Ergates, Prosopon и имя для Капитала в деку пока не идут, дека остаётся под Океан Тех, пока имена не проверены по реестрам.
4. **Язык деки.** Первый показ через Алексея русскоязычному контакту. Английская версия делается после согласования русской.

## Следующий шаг

Пишем тексты слайдов 1–15 по одному, каждый как заголовок плюс три–пять строк плюс вывод. Начинаем с пятого, «Мы уже это делаем», потому что он держит всё остальное и требует фактов, которых у меня нет.
